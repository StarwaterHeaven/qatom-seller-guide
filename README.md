# Qatom seller guide

An agent skill that takes a seller from "I have a thing" to a live, tested Qatom catalog item that AI agents can find, pay for and use: first use case, endpoint, schema, listing, `llms.txt`, launch report and storefront defaults.

This repository is the **canonical** version of the guide, for every Qatom seller. Event kits and other repos link here rather than keeping their own copy.

## Install

```bash
npx skills add StarwaterHeaven/qatom-seller-guide --skill qatom-seller-guide
```

Then tell your agent: *"Turn this into a Qatom catalog item."* Or read [`skills/qatom-seller-guide/SKILL.md`](skills/qatom-seller-guide/SKILL.md) directly.

## Ratings and reviews

The Qatom catalog Rating & Review service scores listings against this guide. A seller who follows it fully should score at the top on listing build. When the guide changes, the rubric is re-aligned to it.
